# 语音记账App高保真原型

> 极简快速 · 语音一落账

## 项目简介

这是一个基于语音输入的记账App高保真原型，采用零确认交互设计，让用户通过语音快速完成记账操作。核心设计理念是"语音说完立刻记账"，大幅提升记账效率。

## ✨ 核心特性

- **🎤 零确认记账**：语音解析后直接入账，无需手动确认
- **🔄 容错设计**：支持模糊语音指令，自动补全/纠错
- **⚡ 极简操作**：核心流程≤2步，避免冗余交互
- **📊 数据可视化**：收支统计、分类占比、趋势分析
- **🎨 现代设计**：采用violet-bloom主题，优雅的紫色系界面

## 📱 界面展示

包含7个高保真界面，均基于iPhone 15 Pro设计（393×852px）：

1. **语音记账首页** - 巨型麦克风按钮、快捷分类、最近记账
2. **账单列表页** - 筛选功能、分类查看、上下拉刷新
3. **数据统计页** - 收支趋势图、分类占比、预算提醒
4. **个人中心页** - 用户信息、成就系统、功能入口
5. **快速编辑页** - 极简表单、一键修改账单信息
6. **设置页** - 系统设置、偏好配置、数据管理

## 🛠️ 技术栈

- **HTML5** - 语义化结构
- **Tailwind CSS** - 现代化样式框架
- **FontAwesome 6.4** - 图标库
- **Chart.js** - 数据可视化
- **Vanilla JavaScript** - 交互逻辑

## 🎨 设计系统

### 尺寸规范
- 设备：iPhone 15 Pro
- 尺寸：393×852px
- 圆角：30px
- Tab栏高度：83px（含安全区）

### 配色方案（violet-bloom主题）
- 主色：`#9333EA` (violet-500)
- 渐变色：`#8B5CF6` → `#9333EA`
- 背景：`#F8FAFC` (slate-50)
- 文字：多层灰度系统

### 交互原则
- 弱引导：减少弹窗，使用轻量toast反馈
- 沉浸式：核心操作占满屏幕
- 容错性：支持一键编辑而非重新录入

## 🚀 快速开始

1. 克隆仓库到本地
2. 直接在浏览器中打开 `prototype/index.html` 查看所有界面
3. 各个界面可独立访问或通过主入口预览
