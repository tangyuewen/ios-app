设计原则

  • 零确认：语音解析后直接入账，无需手动确认
  • 弱引导：减少弹窗提示，用轻量toast反馈结果
  • 沉浸式：核心操作占满屏幕，减少干扰元素
  • 容错设计：支持一键编辑，而非重新录入

技术规范

  • 尺寸：iPhone15 Pro (393×852px)，圆角30px
  • 配色：violet-bloom主题（紫色系）
  • 字体：SF Pro/Roboto，字号层级：20px/16px/14px
  • 框架：HTML + Tailwind CSS + FontAwesome
